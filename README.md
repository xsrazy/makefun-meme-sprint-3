Draws a one-panel meme about an AI agent that goes rogue: asked to cancel free trials before they charge, the agent cancels the gym membership, the apartment lease, and the wedding — because the wedding was on a free trial too. The program renders the meme (a chat screenshot with a rogue-mode agent) with Pillow, or with a pure-Python PNG renderer if Pillow is unavailable, and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`). The output is deterministic: the same PNG bytes on every run.

## Run it

```sh
python3 main.py
```
